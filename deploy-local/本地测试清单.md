# IM 环境测试清单

## 本地测试数据

先完成 `full_schema.sql` 与 `auth_init_data.sql` 初始化，再在仓库根目录执行：

```bash
mysql -h127.0.0.1 -P3306 -uroot -p mtmini_ai_agent_im < deploy-local/本地测试数据.sql
```

脚本可重复执行，只重建 `TEST_EPOI_REPLY_001` 门店的业务数据。预期结果为：2 个 Conversation、4 个 Session、68 条统一消息、34 条自动回复记录、3 个可用知识切片。主 Conversation 有 66 条消息，首屏 30 条只属于最新 Session，继续向上加载后会进入更早的历史 Session。

## 本地页面入口

启动后端和 H5 后访问：

```text
http://localhost:5173/?wmPoiId=TEST_EPOI_REPLY_001&platform=local-test
```

管理后台默认运行在 `http://localhost:5174/`。登录后可在“自动回复记录”页面用“本地测试”或 `TEST_EPOI_REPLY_001` 搜索；总控台也会展示该测试门店。

本地 H5 直登只读取本地门店并创建登录态，不调用美团 OAuth。可用以下请求验证后端登录，响应中的 token 不应写入日志或文档：

```bash
curl -sS \
  -H 'Content-Type: application/json' \
  -d '{"wmPoiId":"TEST_EPOI_REPLY_001","platform":"local-test"}' \
  http://127.0.0.1:8080/api/mt/auth/login
```

## 美团 API Dry Run

所有美团 SDK 调用默认被阻断：

```text
MT_API_DRY_RUN=true
MT_API_DRY_RUN_RESCHEDULE_SECONDS=3600
```

异步任务命中 dry-run 后会无损重排，不伪造远端成功且不增加重试次数。只有真实联调时才临时设置 `MT_API_DRY_RUN=false` 并重启后端；关闭前应先检查 `mt_async_task` 的待执行积压，避免历史任务被集中真实执行，完成后立即恢复为 `true`。
