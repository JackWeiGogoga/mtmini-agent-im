# 美团接口调用索引

## 目的

- 统一登记仓库内所有和美团相关的外部调用与关键接入点，方便排查收费接口使用位置。
- 同时覆盖两类调用方式：
  - 美团 SDK 调用
  - 手动 HTTP 调用
- 同时登记美团主动回调入口、H5 拉起入口，以及可能触发真实调用的手工联调测试。

## 当前结论

- 生产环境中，真正向美团发起外部请求的代码全部在 `backend/`。
- `h5/` 和 `frontend/` 当前没有直接请求美团开放平台；它们只调用本系统后端接口。
- 自动调价链路当前仍会真实调用美团计划状态查询接口；查询计划状态遇到明确鉴权失败时，会刷新 token 并重试一次，仍失败后标记 `mt_access_token.auth_status=2` 并关闭本地推广总开关。推广开关写接口和计划出价写接口已切到 dry run，只打印日志，不真实调用美团。
  - `backend/src/main/java/com/gogoga/backend/client/MtPromotionOpenApiClient.java`
- 每日门店营业分析流量同步、每日/授权后推广广告数据同步遇到明确鉴权失败时，也会刷新 token 并重试一次；仍失败后标记 `mt_access_token.auth_status=2` 并关闭本地推广总开关。指标解密接口本次仍按原失败路径处理，不触发授权状态更新。
  - `backend/src/main/java/com/gogoga/backend/service/MtMeituanAuthorizationFailureHandler.java`
  - `backend/src/main/java/com/gogoga/backend/service/MtPoiTrafficDailyService.java`
  - `backend/src/main/java/com/gogoga/backend/service/MtPromotionAdDataService.java`
- H5 首页只读取本地 `mt_access_token.auth_status` 展示授权状态；当前不提供 H5 手动授权探测入口，不会因首页展示额外真实调用美团接口。
- H5 首页和管理后台切换推广总开关时，会额外真实调用开发者接口同步订单推送状态：
  - 开启推广总开关 -> 开启订单推送（`blockMsgList=[]`）
  - 关闭推广总开关 -> 停止订单推送（`blockMsgList=[16102]`）
- 功能权益过期关停任务 `MtPromotionRightExpiryShutdownTask` 会按“关闭美团推广计划 -> 停止订单推送 -> 关闭本地推广开关”的顺序收敛状态；其中推广计划状态写接口仍受 `mt.promotion.write-dry-run` 控制，订单推送停止是真实外呼。
- 首次授权成功后，系统会入队 `AUTH_BLOCK_ORDER_PUSH` 数据库异步任务停止订单推送；任务执行前会重新检查推广总开关，若商户已开启推广则跳过停止。
- `MtPromotionAutoBidTask`、`MtPoiTrafficDailyTask`、`MtPromotionAdDataTask` 等依赖美团授权 token 的候选查询会过滤 `auth_status = 1`；已标记 `REAUTH_REQUIRED(2)` 的门店不会继续触发这些真实外呼。
- 仓库内存在多个人工联调测试，会真实调用美团授权门店、广告相关接口与营业分析接口，执行前必须确认。

## 一、生产环境真实外呼美团

### 1. 授权换 token

- 功能：美团授权回调后，用授权码换取 `accessToken` / `refreshToken`
- 调用方式：SDK
- 入口链路：
  - `backend/src/main/java/com/gogoga/backend/controller/MtAuthController.java`
  - `/api/callbacks/meituan/auth`
- 真实调用位置：
  - `backend/src/main/java/com/gogoga/backend/service/MtAuthService.java`
  - `meituanClient.getOAuthToken(mtProperties.getBusinessId(), code)`
- 代码索引：
  - `backend/src/main/java/com/gogoga/backend/controller/MtAuthController.java:45`
  - `backend/src/main/java/com/gogoga/backend/service/MtAuthService.java:48`
- 请求特征：
  - SDK 方法：`getOAuthToken`
  - API 地址：`/oauth/token`
  - 关键参数：`businessId`、`code`、`grantType=authorization_code`
- 费用说明：免费
- 说明：
  - 这是美团授权完成后的第一跳。
  - 调用成功后会同步保存门店和 token，并在事务提交后投递授权后补偿异步任务。

### 2. 查询授权门店详情

- 功能：根据刚换到的 `accessToken` 查询授权店铺信息
- 调用方式：SDK，自定义请求类
- 真实调用位置：
  - `backend/src/main/java/com/gogoga/backend/client/MtShopClient.java`
  - `backend/src/main/java/com/gogoga/backend/client/request/MtPoiDetailRequest.java`
- 代码索引：
  - `backend/src/main/java/com/gogoga/backend/service/MtAuthService.java:55`
  - `backend/src/main/java/com/gogoga/backend/client/MtShopClient.java:38`
  - `backend/src/main/java/com/gogoga/backend/client/request/MtPoiDetailRequest.java:19`
- 请求特征：
  - 请求类：`MtPoiDetailRequest`
  - API 地址：`/wmoper/ng/poi/detail`
  - SDK 标识：`apiName=wmoperng_query_poi_detail`
  - 鉴权要求：`needAuth=true`
- 费用说明：收费管理 API，`0.3 元 / 百次`
- 说明：
  - 授权回调主链路会先同步查询一次，结果用于初始化或更新本地 `mt_shop` 门店信息。
  - 当前授权回调链路临时跳过该收费接口的本地算力扣减，避免商户算力不足时影响 `access_token` / `refresh_token` 核心保存；后续恢复扣减时必须使用独立事务或异步补偿。
  - 当前自动调价任务在发现候选门店 `shipping_time` 为空时，也会使用当前门店 `accessToken` 再拉一次详情，尝试补齐营业时间后再做时段判断。

### 4. 刷新 access token

- 功能：刷新即将过期的美团授权 token
- 调用方式：SDK
- 触发方式：定时任务；自动调价鉴权失败补偿重试
- 代码索引：
  - `backend/src/main/java/com/gogoga/backend/task/MtAccessTokenRefreshTask.java:27`
  - `backend/src/main/java/com/gogoga/backend/service/MtAccessTokenService.java`
  - `backend/src/main/java/com/gogoga/backend/service/MtPromotionAutoBidService.java`
- 请求特征：
  - SDK 方法：`refreshToken`
  - API 地址：`/oauth/refresh`
  - 关键参数：`businessId`、`refreshToken`、`grantType=refresh_token`、`scope=all`
- 费用说明：免费
- 说明：
  - 定时任务按 `mt.token.refresh-cron` 执行。
  - 自动调价查询点金推广计划状态遇到明确错误码 `OP_UNIAUTH_FAILED` 时，会按门店刷新 token 并用新 token 重试一次；普通错误文案不作为重新授权判断依据。
  - 如果刷新或重试后仍确认鉴权失败，系统会将该门店 `mt_access_token.auth_status` 标记为 `2(REAUTH_REQUIRED)`，并关闭本地 `promotion_enabled`。
  - 这是生产周期性调用点，容易被忽视；鉴权失败补偿也是生产真实外呼。
