# 美团接口调用索引

## 范围说明

- 统一登记仓库内所有和美团相关的外部调用与关键接入点。
- `backend/` 是生产环境中真正向美团发起外部请求的代码位置。
- `h5/` 和 `frontend/` 不直接请求美团开放平台；它们只调用本系统后端接口。
- 评价自动回复任务依赖有效门店授权 token 和门店权益，候选查询会过滤 `mt_access_token.auth_status = 1`。

## 订单推送关闭

- 自动回复业务不接收美团订单数据，不保留订单回调入口，也不维护 `mt_order` / `mt_order_detail`。
- 门店授权后，`MtAuthAsyncTaskService` 会入队 `AUTH_BLOCK_ORDER_PUSH`，通过“更新开发者绑定门店消息推送屏蔽列表”接口关闭订单类消息推送。
- 本地保留 `MtOrderPushControlService` 和对应手动联调入口，仅用于控制美团订单推送开关状态。

## 评价自动回复

### 查询门店评价信息

- 文档：`10.6.1 查询门店评价信息`
- 地址：`https://api-open-cater.meituan.com/wmoper/ng/comment/queryCommentList`
- SDK request：`com.meituan.sdk.model.wmoperNg.comment.queryCommentList.QueryCommentListRequest`
- 本地入口：
  - `backend/src/main/java/com/gogoga/backend/task/MtCommentAutoReplyTask.java`
  - `backend/src/main/java/com/gogoga/backend/service/MtCommentAutoReplyService.java`
- 固定参数：
  - `startTime`：当天 0 点往前 `mt.comment.lookback-days` 天，默认 7 天。
  - `endTime`：当天 0 点。
  - `offset`：分页起点。
  - `limit`：默认 20，最大 20。
  - `replyStatus`：`0`，只查询未回复。
  - `bizKey`：当前实现按 `biz~1002~Waimai~{ePoiId}` 拼接。
- 落库：评价字段保存到 `mt_comment`，`comment_order_detail` 和原始响应以 JSON 保存。
- 幂等：`mt_comment.comment_id` 唯一，用户首次评价和追加评价同 ID 时更新同一条记录。

### 根据评价id添加商家回复

- 文档：`10.6.2 根据评价id添加商家回复`
- 地址：`https://api-open-cater.meituan.com/wmoper/ng/comment/addReply`
- SDK request：`com.meituan.sdk.model.wmoperNg.comment.wmoperCommentAddReply.WmoperCommentAddReplyRequest`
- 本地入口：
  - `backend/src/main/java/com/gogoga/backend/task/MtCommentAutoReplyTask.java`
  - `backend/src/main/java/com/gogoga/backend/service/MtCommentAutoReplyService.java`
- 固定参数：
  - `commentId`：查询评价接口返回的评价 ID。
  - `ePoiId`：门店 `mt_shop.epoi_id`。
  - `reply`：当前固定为 `mt.comment.default-reply`，默认“很好”。
- 落库：成功后更新 `mt_comment.reply_status=1`、`auto_reply_status=SUCCESS`、`auto_reply_content`、`auto_reply_at`；失败记录 `auto_reply_status=FAILED` 和错误摘要，等待后续任务重试。
