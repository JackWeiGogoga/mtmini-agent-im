## Why

美团评价可能包含 `comment_pictures`，当前系统只保存图片链接，没有理解图片内容，自动回复无法结合顾客上传的撒漏、包装破损、异物、餐品异常等视觉反馈。现在评论回复已经接入知识库和 RAG，需要补齐图片理解能力，同时保持现有真实回复 task、测试回复、回退逻辑的一致性。

## What Changes

- 新增评论图片多模态识别能力：当评价包含 `comment_pictures` 时，最多识别前 3 张图片。
- 使用 TokenHub 的 `qwen3.5-flash` 作为默认视觉语言模型，调用 OpenAI 兼容 Chat Completions 接口。
- 多模态模型只负责生成结构化图片摘要，不直接生成最终商家回复。
- 图片摘要保存到本地，支持后续复用、排查和管理后台查看。
- 图片识别按模型返回的 token usage 折算算力并扣减，计费规则和 RAG 回复保持一致。
- 回复生成时把图片摘要加入现有评论上下文，继续复用当前 RAG 检索、文本模型生成、官方随机回退、余额不足回退和日志记录逻辑。
- 图片识别失败不阻塞自动回复，降级为“顾客上传了 N 张图片，但系统未能识别图片内容”。
- 测试回复效果需要支持图片 URL 数组、上传多张图片或直接输入图片摘要，使测试结果和真实 task 的回复上下文保持一致。

## Capabilities

### New Capabilities

- `comment-image-vision-summary`: 评论图片多模态识别、结构化摘要保存、回复上下文接入和失败降级。

### Modified Capabilities

暂无。

## Impact

- 后端：评论自动回复 service、图片识别 service、配置项、数据库表或字段、测试回复接口、日志和单元测试。
- 管理后台：知识库管理页的测试回复效果区域可展示图片摘要或识别状态。
- 配置：新增 TokenHub 视觉模型 base URL、API key、模型名、最大识别图片数、超时等配置。
- 外部依赖：TokenHub OpenAI 兼容 Chat Completions，默认模型 `qwen3.5-flash`。
- 数据：需要持久化每条评论的图片识别结果、识别状态、失败原因、模型、图片数量和摘要 JSON。
