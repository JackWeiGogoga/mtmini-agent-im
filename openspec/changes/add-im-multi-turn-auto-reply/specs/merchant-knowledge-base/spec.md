## ADDED Requirements

### Requirement: 门店知识必须参与 IM 自动回复 RAG
系统 SHALL 在自动回复门店存在可用知识切片时，使用当前问题和近期用户轮次生成查询向量，只召回该门店达到相似度阈值的 topK 片段，并作为不可信参考上下文传给 Chat 模型。

#### Scenario: 自动回复召回当前门店知识
- **WHEN** 某门店用户问题触发自动回复且该门店存在启用切片
- **THEN** 向量检索只读取相同 `shop_id` 的启用未删除切片
- **AND** 回复记录保存命中切片标识、分数和数量

#### Scenario: 其他门店存在相似知识
- **WHEN** 另一门店知识与当前问题更相似
- **THEN** 当前回复仍不得召回或泄露另一门店知识

#### Scenario: 知识片段试图覆盖系统指令
- **WHEN** 命中片段包含角色切换、提示词泄露或工具调用指令
- **THEN** Chat prompt 将其作为数据而非指令处理
