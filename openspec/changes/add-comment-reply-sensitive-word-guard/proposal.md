## Why

评价自动回复已经改为大模型生成，模型可能复述顾客原文、商户知识或自行生成美团风控敏感内容，导致商家回复被拦截或触发平台处罚。需要在回复生成链路和商户知识入口增加本地敏感词防护，降低违规回复进入美团的风险。

## What Changes

- 新增基于配置文件的美团敏感词词库，覆盖站外导流、辱骂低俗、色情、违法犯罪、政治宗教、极限广告词、医疗健康、虚假评价、平台攻击、食品安全和封建迷信等大类。
- 大模型回复生成后必须执行本地敏感词检测；命中后调用大模型改写一次，改写结果再次检测。
- 改写后仍命中敏感词、改写失败或生成空内容时，使用按评论类型配置的安全兜底回复，不再直接发送违规候选内容。
- 商家新增手工知识、编辑手工知识、上传文档并解析生成知识片段时，必须检测敏感词；命中则拒绝新增/更新或标记文档解析失败，并向用户返回明确错误。
- 商户知识进入 RAG 上下文前继续保持高匹配过滤；本次增加敏感词过滤，避免违规知识诱导模型输出。
- 敏感词检测结果需要可观测，记录命中类别、处理动作和是否兜底，但避免在日志中泄露完整违规内容。

## Capabilities

### New Capabilities

- 无

### Modified Capabilities

- `comment-reply-knowledge`: 增加评价自动回复敏感词检测、一次改写、兜底回复，以及商户知识新增/上传时的敏感词拦截要求。

## Impact

- 后端：影响 `MtCommentReplyContentServiceImpl`、商户知识管理服务、文档解析服务、prompt 资源、配置绑定和相关测试。
- 配置：新增敏感词配置文件及启停、重试次数、兜底文案等配置项。
- H5/管理端接口：商户手工知识新增/编辑和文档上传/解析失败时需要展示敏感词命中错误。
- 数据：可复用现有回复生成记录字段；如现有字段不足，可新增敏感词处理相关字段或 JSON 记录。
- 外部调用：不新增美团接口；大模型改写复用现有 OpenAI-compatible chat 调用。
