## Why

当前差评处理在自动回复后只执行自动申诉，无法主动通过美团评价匿名群聊联系顾客核实问题；现有管理后台也只能在总控台按单店查看有限的自动回复日志，无法统一复盘评价回复、差评申诉和建群消息的完整结果。

本变更新增独立的差评 IM 跟进任务，并提供覆盖所有评价的只读处理日志页面，在不影响现有自动回复和申诉链路的前提下提升售后触达能力与问题排查效率。

## What Changes

- 差评自动回复成功后，在现有 `COMMENT_AUTO_COMPLAINT` 之外独立入队 `COMMENT_AUTO_IM_FOLLOW_UP`；两者继续同时执行、互不依赖，复用现有“差评处理/申诉”开关，只处理变更上线后新触发的差评。
- 调用美团 `wmoper/ng/im/createGroup` 创建评价联系群，固定 `group_type=1`、传入 `comment_id`，持久化 `group_id` 和群状态。
- 调用美团 `wmoper/ng/im/msg/send` 发送匿名群聊文本，固定 `biz_type=4`、`msg_type=0`、`msg_source=1`、`scene_tag=-1`，携带唯一 `msg_id`、10 位 `cts`、`comment_id` 和 `group_id`。
- 使用 16 字节 `imSecret` 的 UTF-8 字节同时作为 AES key 和 IV，以 `AES/CBC/PKCS5Padding` 加密正文并输出标准 Base64；密钥只从开发者级安全配置读取。
- 新增后台可配置提示词 `COMMENT_IM_FOLLOW_UP_MESSAGE`。最终模板不得提及补偿、退款、赔付或补发，礼貌引导顾客提供订单信息和方便联系的手机号，限制 150 个 Unicode 字符、单段纯文本并带 1 至 2 个表情符号。
- 模型失败、空输出、格式或合规检查失败时，不重试模型，改用固定兜底文案继续建群和发送；记录消息来源和兜底原因。
- IM 消息生成纳入算力计费，使用评价级唯一 requestNo 防止重复扣费；模型成功按实际 usage 计费，固定兜底按配置的兜底算力计费。
- 创建群和发送消息分别支持 dry run，且两个开关默认开启。dry run 不调用美团、不伪造成功，也不占用该阶段唯一一次真实调用机会；后续可按“先建群、再发消息”逐步关闭。
- 创建群和发送消息的真实调用都最多尝试一次。业务失败、异常、超时和结果未知均记录为终态失败，不自动重试；通过调用前持久化 attempt 标记阻止 worker 重领、超时回收或重复任务再次外呼。
- 新增管理后台“评价处理日志”页面，以所有 `mt_comment` 为主数据分页展示评价内容、自动回复、差评申诉、IM 建群/发消息状态、耗时、算力和安全错误摘要，支持筛选与详情查看，不提供人工重试或修改操作。
- 同步更新 `docs/美团接口调用索引.md`，登记两个新增美团调用的 SDK 类、参数、dry run、加密、落库、不重试和门店隔离规则。

## Capabilities

### New Capabilities

- `negative-comment-im-follow-up`: 差评自动创建评价联系群并发送 AI 售后首条消息，包括触发条件、提示词与固定兜底、算力计费、内容合规、AES 加密、两个美团接口、默认 dry run、单次真实尝试、状态持久化和门店隔离。
- `admin-comment-processing-log`: 面向管理后台的全量评价处理日志，包括跨门店分页筛选、自动回复/差评申诉/IM 跟进聚合详情、权限控制、数据脱敏和只读复盘页面。

### Modified Capabilities

无。

## Impact

- 后端异步任务：新增任务类型、payload 和 worker 分发；调整差评自动回复成功后的后置任务入队；IM 任务配置为外部调用失败不重试。
- 后端业务：新增 IM 跟进、消息生成与兜底、渠道合规、AES 加密和美团 typed SDK 调用；复用门店设置、授权 token、系统提示词和算力体系。
- 数据库：新增 `mt_comment_im_follow_up`，为 `mt_comment` 增加 IM 状态快照，初始化提示词与新后台菜单/权限；申诉继续读取现有 `mt_comment_complaint`。
- 管理后台：新增独立路由、筛选表格和处理详情抽屉；原总控台单店自动回复日志保持不变。
- 安全：新增开发者级 `imSecret` 配置；接口和日志禁止输出 access token、密钥、完整密文和完整外部请求体，页面只展示业务需要的生成明文与安全错误摘要。
- 测试与文档：新增触发隔离、提示词/兜底、计费、AES 固定向量、默认 dry run、单次尝试、重复领取、全量日志查询与后台权限测试，并更新美团接口调用索引。
