## Why

当前 H5 日志页仍是占位页，商家无法查看评价自动回复的处理记录，也无法核对顾客评价、图片、AI 回复和分析结果。评价自动回复链路已经在本地保存评价与回复字段，现在需要把这些记录以移动端友好的方式展示出来，承接首页“查看日志”入口。

## What Changes

- 将 H5 `/pages/log/index` 从占位页改造成评价自动回复日志页，整体布局参考老项目日志页的固定顶部说明、分组列表、加载更多、空态和底部 tabbar。
- 顶部说明改为评价颜色标识：红标差评、绿标好评、灰色中评。
- 每条日志展示顾客消息文本、图片列表、AI 回复文案、AI 分析文案，其中 AI 分析在当前流程暂未真实产出时先展示固定文案“AI 分析结果”。
- 日志标识颜色按评价类型映射：`BAD`/0-2 星为红色，`GOOD`/4-5 星为绿色，`NEUTRAL`/3 星为灰色。
- 支持按时间页码分页加载、下拉刷新、空态、失败提示，并保持商家只查看当前门店记录。
- 日志范围展示当前门店所有已保存的评价记录，不按自动回复状态过滤；缺少回复内容时在 H5 展示兜底文案。
- 如当前后端没有可直接给 H5 使用的评价日志接口，新增门店态只读分页接口，从 `mt_comment` 读取已保存评价与自动回复字段。

## Capabilities

### New Capabilities

- `h5-comment-reply-log`: 商家端 H5 查看当前门店评价自动回复日志，包括评价文本、图片、AI 回复、AI 分析占位文案、评价类型标识和分页浏览。

### Modified Capabilities

- 无。

## Impact

- `h5/src/pages/log/index.vue`：替换占位页，复用老项目日志页体验并改为评价自动回复日志。
- `h5/src/utils/mt-auth.js`：如需新增 H5 日志请求方法，统一放在该文件中。
- `backend/src/main/java/com/gogoga/backend/controller/`、`service/`、`mapper/`、`vo/`：如无现成接口，需要新增当前门店范围内的评价回复日志分页查询。
- `backend/src/main/resources/mapper/`：如新增查询方法，需要同步维护 Mapper XML。
- 不新增或修改美团外部 API 调用；通常不需要更新 `docs/美团接口调用索引.md`。
